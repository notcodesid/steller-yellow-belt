## `wallet-options.png`

**Required by the Level 2 checklist: "Screenshot: wallet options available".**

How to capture:

1. `cd frontend && npm install && npm run dev`
2. Open http://localhost:5173
3. Click **Connect wallet**
4. Screenshot the StellarWalletsKit auth modal showing the wallet options
   (Freighter, Albedo, xBull, Rabet, Lobstr, Hana, etc.)
5. Save it over `wallet-options.png`
